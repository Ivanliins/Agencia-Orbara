# Comercial Google Ads — Orbara (30s)

Motion graphics feito em HTML + GSAP e renderizado quadro a quadro.

- `commercial.html` — animação (abra no navegador com `?f=h` ou `?f=v` para ver o preview)
- `render.cjs` — renderiza para MP4 (Playwright + ffmpeg): `node render.cjs h out/video-16x9.mp4`
- `music.py` — trilha original sintetizada (numpy), alinhada aos cortes: `python3 music.py out/trilha.wav`
- `out/orbara-google-ads-16x9.mp4` e `out/orbara-google-ads-9x16.mp4` — versões finais com trilha
